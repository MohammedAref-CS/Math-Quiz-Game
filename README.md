🧮 Math Quiz Game

A simple C++ Console Math Quiz Game designed to practice problem-solving and core C++ concepts.

🎮 How It Works

The player chooses:

- 🔢 Number of questions
- 📊 Difficulty: Easy, Medium, Hard, or Mix
- ➕ Operation: Add, Subtract, Multiply, Divide, or Mix

The program then generates random questions and checks each answer.

✅ Answer Feedback

- 🟢 Correct Answer: The console changes to green.
- 🔴 Wrong Answer: The console changes to red and a sound alert is played, then the correct answer is displayed.

At the end, the game shows the number of correct and wrong answers and whether the player passed or failed.

🧠 What I Learned

Through this project, I practiced:

- "enum" and "struct"
- Arrays and functions
- Passing data by reference
- Random number generation
- "switch", loops, and conditions
- Organizing a program into smaller functions
- Problem-solving and logical thinking
